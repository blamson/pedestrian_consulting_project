# Documentation

This directory contains many subdirectories that organize all of the notes and sources used in this project. 

## Navigation

- `glossary.md`: Definitions and explanations for key terms, jargon, and initialisms. 
- `knowledge-log.md`: A historical record of notes and thoughts as progress was made through the project.
- `davyd-work-log.md`: Davyd's historical record of work done. 
- `davyd_notes/`: Directory containing all of Davy'd notes during this project. 
- `sources/`: Contains all of the web articles and pdfs used as reference during this project, alongside explanations for everything in it. 
- `notes/`: Contains various unorganized notes and writeups, all in markdown. 
- `images/`: Contains images
